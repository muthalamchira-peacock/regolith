Regolith

A game where students run a Moon or Mars outpost for 60 sols, balancing power, radiation shielding, life support, food and mass. A rover EVA layer logs data usable for rover AI.
Play: https://muthalamchira-peacock.github.io/regolith/
Data card: records are JSONL: outpost, eva, hazard_tag, selfright, eva_end. Simplified physics supports high-level policy and perception, not servo control.
AI use: The game code was generated with Claude (Anthropic) and edited by crocodilerulz. The concept and the rover integration are the team’s.
